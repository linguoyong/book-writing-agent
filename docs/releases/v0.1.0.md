# v0.1.0

首个公开发布版本，提供 Windows x64 安装包，使用 MIT 协议。

## 模型连接测试

- 模型设置页的每个写作模型、抽取模型和审稿模型均增加「测试连接」按钮。
- 直接测试当前填写的配置，无需先保存；测试不会改动配置或写入会话。
- 成功时显示实际使用的模型和耗时；失败时提示认证、权限、模型名、额度、网络或超时问题。
- 支持复用已保存、显示为 `***` 的密钥；清空密钥后测试不会误用旧密钥。
- 审稿模型名留空时，测试当前默认写作模型，包括尚未保存的修改。
- 修改配置后清除旧测试结果；测试期间防止重复点击，并在约 30 秒内结束请求。

## 安装与首次配置

下载 `写作 Agent-0.1.0-setup.exe` 后运行，选择安装目录。安装包内含 Python 后端，无需另行安装 Python 或开发依赖。

打开模型设置，填写模型服务的 Base URL、API Key 和模型名，点击各自的「测试连接」，确认成功后点击「保存」。
测试会向所配置的模型服务发送一条简短消息，按服务商规则计费。
